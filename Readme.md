# Hydra

Hydra is an x86 operating system written in assembly and c. It is in kernel building stage right now. I am aiming for a hybrid kernel and beautiful GUI with fast performance. 


## Requirements
1. grub
2. i686-elf cross compiler
3. nasm
4. qemu-system-x86_64

## Build
make
builds everything

make run
builds and boot os on qemu
